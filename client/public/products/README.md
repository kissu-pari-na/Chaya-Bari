# Product images

Static product images served by Vite at the site root.

A file here at `client/public/products/daab-pudding.jpg` is served as `/products/daab-pudding.jpg`, which is the `imageUrl` wired for **ডাব পুডিং** (Daab Pudding) in `server/prisma/seed.ts`.

Drop the image file here (keep the exact filename `daab-pudding.jpg`) and it will render on the product card and detail page.
